How to read these

Every mockup uses the app's real tokens, companions, and check-in controls — only the arrangement changes, so any one could drop into the existing dashboard. Screens are shown in the product's light theme regardless of this page's theme.

The two levers vary independently. Companion prominence ranges from a centered portrait (01, 05) through a persistent rail (02) to a header anchor (03, 04). Habit division ranges from filled tiles (01) and elevated sub-cards (03) to a status stripe (04) and a labeled ruled list (05). Approaches can be mixed — e.g. Crown's portrait with Spotlight's status stripes.
